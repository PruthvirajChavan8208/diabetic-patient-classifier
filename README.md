# Diabetic Patient Classification Project

This is a Machine Learning web application that predicts the risk or status of diabetes in a patient based on clinical metrics using a trained model.

##  Live Demo
[Click here to try the app]->(https://diabetic-patient-classifier-kqkgbtlsnenexsp7mdgjmf.streamlit.app/)

## 🚀 Features
* Web Interface: Built with Streamlit for a user-friendly experience.
* Model: Uses a trained machine learning model (model.pkl).
* Real-time Prediction: Enter health metrics and get an instant risk assessment.

## 🛠️ Tech Stack
* Language: Python
* Libraries: Pandas, NumPy, Scikit-learn, Streamlit
* Deployment: GitHub & Streamlit Cloud

## 📁 Project Structure
* app.py: The main script for the Streamlit web interface.
* model.pkl: The trained machine learning model.
* scaler.pkl & pipe.pkl: The data preprocessing and scaling artifacts.
* cleaned: The dataset used for training the project.
* requirements.txt: List of Python libraries needed to run the app.
